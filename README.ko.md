# first-contribution

오픈소스에 처음(혹은 그 다음) PR을 실제로 성사시키도록 도와주는 [Claude Skill](https://www.anthropic.com/news/skills)입니다 — 3개월 전에 이미 닫혔어야 할 `good first issue`를 붙잡고 한나절을 날리는 대신에요.

## 문제 상황

`good first issue` 라벨은 생각보다 자주 거짓말을 합니다. 인기 있는 레포일수록, 2023년에 붙은 라벨은 이미 다른 PR로 해결됐거나, 조용히 마무리됐는데 이슈만 안 닫힌 경우가 흔해요. 신나서 들어가서 코드를 읽기 시작했는데, 6개월 전에 이미 걸려있는 PR을 발견하는 식이죠.

이 스킬은 정확히 그 일이 저에게 한 오후에 같은 레포에서 두 번 연속으로 일어나서 만들었습니다.

## 뭘 하나요

1. **감이 아니라 실제 데이터로 레포를 평가** — GitHub API에서 오픈 이슈 수, good-first-issue 개수, 마지막 활동 시점, 외부 기여자 비율 같은 실제 수치를 가져와서 "이 레포 초보자한테 괜찮나"를 감이 아닌 비교로 판단합니다.
2. **추천하기 전에 죽은 이슈를 걸러냄** — Development 섹션의 연결된 PR, Assignee, 최근 코멘트("이거 해결된 듯")까지 실제로 확인한 이슈만 후보에 올립니다.
3. **커뮤니티 채널을 찾고 메시지 초안까지 작성** — README에서 Discord/Slack 링크를 뽑아오고, 이슈 클레임 코멘트 초안을 써주고, 라벨이 전멸했을 땐 "혹시 기여 어떻게 하나요?" 같은 뻔한 문구 대신 구체적인 요청 메시지를 작성해줍니다.
4. **실제 기여 과정을 함께 진행** — 레포를 클론하고, CONTRIBUTING.md를 읽고, 관련 파일로 스코프를 좁히고, 수정안을 작성하고, diff를 설명하고, 실제 테스트를 돌리고, 그 프로젝트 스타일에 맞는 PR 설명까지 작성합니다.

## 설치

이 레포에는 두 가지 버전이 있습니다:

- **`first-contribution/`** — 영어 버전, 영어로 응답
- **`first-contribution-ko/`** — 한국어 버전, 한국어로 응답

원하는 언어의 폴더를 Claude Skills 폴더에 넣거나, 해당하는 `.skill` 파일을 Claude.ai / Claude Code / Cowork에 바로 로드하세요. 서로 독립적인 스킬이라 하나만 설치해도, 둘 다 설치해도 됩니다.

```
your-skills-dir/
└── first-contribution-ko/
    ├── SKILL.md
    └── references/
        ├── repo-evaluation-criteria.md
        ├── issue-triage-checklist.md
        └── message-templates.md
```

## 예시

> "RAG나 LLM 관련 오픈소스에 기여하고 싶어, 좋은 레포랑 이슈 찾아줘"

Claude가 후보 레포의 실제 지표를 가져와 이유와 함께 추천하고, 그 레포의 good-first-issue 목록을 검증해서 진짜 열려있는 이슈만 골라준 다음, 커뮤니티 채널과 메시지 초안까지 준비해서 실제 수정 작업까지 안내합니다.

## 진행 상황

이 스킬은 제가 직접 기여하면서 실사용 결과를 바탕으로 계속 다듬는 중입니다. 죽은 이슈를 추천하거나, 레포 판단이 틀리거나, 프로젝트 관례를 놓치는 경우를 발견하시면 이슈로 알려주세요 — 정확히 그런 피드백이 체크리스트를 더 정교하게 만듭니다.
